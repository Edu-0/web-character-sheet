# Ícones do aplicativo

O símbolo é o escudo/seta já utilizado no cabeçalho, adaptado para o ícone de instalação. SVG e PNGs acompanham a [licença do código original](../../LICENSE), com seus termos de uso não comercial e atribuição. Não incorporam conteúdo de livros, bibliotecas de arte ou novas marcas de terceiros.

`icon.svg` é a fonte. `icon-192.png` e `icon-512.png` são usados pelo manifesto; `icon-180.png` é o ícone de toque. Todos têm fundo opaco, com o símbolo central dentro da área segura para recorte. Regenere com `node scripts/build-icons.mjs` (Playwright e Microsoft Edge) e depois `npm run build:offline`.
